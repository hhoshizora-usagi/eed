# DDE

ブラウザで遊べるリズムゲームです。音楽に合わせて、流れてくる矢印をタイミングよく押して遊びます。

## 遊び方
1. `DDE_v0.2.html` を開く
2. 「スタート」を押す
3. 音楽に合わせて、矢印にタイミングよく合わせて押す
4. 判定（PERFECT / GREAT / MISS）とコンボを競う

## 特徴
- パソコン・スマホどちらのブラウザでも遊べる
- 難易度を選べる
- スコア・コンボ・判定を表示
- タイミング調整機能（音と矢印のズレを補正）

## 動作環境
- サーバー不要。ブラウザだけで動きます
- 対応：Chrome、Safari（パソコン・スマホ）
- `DDE_v0.2.html` をブラウザで開くだけでOK
