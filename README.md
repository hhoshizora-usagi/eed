# DDE ダンスダンスエボリューション v0.3

1つのファイルだけで動く、オフラインのリズムゲームだよ。

## あそび方
- タイトル画面で「曲」「流れる向き」「むずかしさ」をえらんでから、スタート！
- 矢印がワクにピッタリ重なった瞬間に押そう
- パソコン：← ↓ ↑ → または D F J K
- スマホ：矢印のレーン（たての列）をタップ（2本同時もOK）

## えらべるもの
- 曲：DIGITAL STAR（BPM150・インスト）／ RISING HIGHER（BPM120・ボーカル入り・タイトルに「NEW」マーク）
- 流れる向き：ノーマル（下から上）／ リバース（上から下）。えらんだボタンは色がつくよ（ノーマル＝紫、リバース＝ピンク）
- むずかしさ：やさしい ／ ふつう ／ むずかしい

## メモ
- ベスト記録は曲ごと・むずかしさごとに保存されるよ
- 音のズレが気になるときは、タイトル画面の「タイミング調整」を動かしてみてね
- スマホのマナーモードでも音が出るようにしてあるよ
- むずかしさのボタンの数字は、その曲の矢印の数だよ
